# Synthetic Data

A small FOCUS-shaped sample (7 days, 40 resources, seed 42) for demoing the free tools without touching real billing. `sample/billing.csv` plus `sample/ground_truth.json` naming every planted defect: a spike day, untagged resources, tag variants, idle resources, an orphaned bucket, old-generation SKUs, and unused commitments.

Generated by the Groundwork kit's generator. The ground truth is the answer key: a tool demo against this sample is verifiable, not eyeballed.
